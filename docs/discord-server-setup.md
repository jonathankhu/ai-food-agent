# 設定 Discord Server 與頻道

這份文件帶你做三件事：

1. 建立一個你自己的 **Server**（Discord 裡的「社群空間」，像一個聊天室大樓）。
2. 建立一個專門給 agent 用的 **頻道**（Server 裡的一個聊天室），並取得它的 `CHANNEL_ID`（頻道的編號）。
3. 產生 **邀請連結**，讓同組同學加入你的 Server。

> 電腦是 **macOS**。文件裡的「右鍵」指的是：在觸控板上用兩指點一下，或是按住鍵盤的 `control` 再點一下。
> Discord 偶爾會改畫面，如果你看到的字和這裡不一樣，找意思最接近的，或是把畫面描述給我。

做完之後，繼續看 [docs/discord-bot-setup.md](discord-bot-setup.md)。

---

## 開始前

- 你需要一個 Discord 帳號。還沒有的話，到 https://discord.com 註冊。
- 用 **Discord 桌面程式** 或 **瀏覽器版**（https://discord.com/app）都可以，下面以桌面程式為準。

---

## 一、建立你自己的 Server

1. 打開 Discord 並登入。
2. 看**畫面最左邊那一條直的圖示列**。找到最下面的 **綠色 `+` 圖示**（滑鼠移上去會寫「新增伺服器」或「Add a Server」），點一下。
3. 跳出視窗，點最上面的 **「親自建立」**（**Create My Own**）。
4. 下一個畫面問你要做什麼用，點 **「僅供我和我的朋友使用」**（**For me and my friends**）。
5. 在「伺服器名稱」欄位輸入名稱，例如 `食物記錄實驗室`。
6. 點右下角的 **「建立」**（**Create**）。

做完後，畫面左邊會多一個你的 Server 圖示，點進去就會看到它。

---

## 二、建立給 agent 用的頻道

新的 Server 預設有一個叫 `一般`（general）的頻道。我們另外開一個專用的，避免和閒聊混在一起。

1. 進到你的 Server。看**左邊第二欄**（Server 的名稱下面）。
2. 找到 **「文字頻道」**（**Text Channels**）這一行。把滑鼠移到那一行的右邊，會出現一個 **`+` 符號**，點它。
3. 在跳出的視窗裡：
   - **頻道類型**：選 **「文字」**（Text），不要選語音。
   - **頻道名稱**：輸入 `food-log`。（Discord 會自動把名稱轉成小寫、把空格變成 `-`。）
   - **私人頻道**（Private Channel）的開關：**保持關閉**。
4. 點 **「建立頻道」**（**Create Channel**）。

左邊會多出一個 `# food-log`，點進去，這就是 agent 要聽的頻道。

---

## 三、取得 CHANNEL_ID

`CHANNEL_ID` 是這個頻道的一串數字編號，agent 靠它知道「只聽這個頻道」。Discord 預設不讓你看到它，要先打開「開發者模式」。

### 3-1 打開開發者模式（只要做一次）

1. 看 Discord **左下角**，你的頭像和名字旁邊有一個 **齒輪圖示**（使用者設定），點它。
2. 在左邊選單往下找，點 **「進階」**（**Advanced**）。
3. 找到 **「開發者模式」**（**Developer Mode**），把開關打開（變成綠色）。
4. 按右上角的 **`ESC`** 或叉叉離開設定。

### 3-2 複製頻道編號

1. 在左邊頻道列表，對 `# food-log` 按 **右鍵**（兩指點觸控板，或 `control` + 點一下）。
2. 在選單最下面找到 **「複製頻道 ID」**（**Copy Channel ID**），點它。
3. 這時編號已經在你的剪貼簿裡了。打開 **「備忘錄」** 或 **「文字編輯」**，按 `command` + `V` 貼上，確認是一串約 18 到 19 位的數字，例如 `1234567890123456789`。
4. 暫時存在那裡，之後要填進 `.env` 檔的 `CHANNEL_ID`。

> `CHANNEL_ID` 不是密碼，但也不要隨便貼到公開的地方（它會讓別人知道你的 Server 結構）。

---

## 四、產生邀請連結，讓同組同學加入

> **先想清楚：誰進了這個頻道，誰就能用你的 Claude 額度。**
> 每個人傳的每一張照片，都會用掉你自己的額度。所以邀請連結請設定「有效期限」和「使用次數」，只給你信任的同學。

### 4-1 產生連結

1. 在左邊 Server 列表的**最上方，點你的 Server 名稱**（例如 `食物記錄實驗室`），會展開一個選單。
2. 點 **「邀請其他人」**（**Invite People**）。
3. 跳出視窗，最下面有一行連結，格式像 `https://discord.gg/xxxxxxx`。

### 4-2 設定有效期限與次數（建議一定要做）

1. 在同一個視窗，點下面的 **「編輯邀請連結」**（**Edit invite link**，是一個小齒輪或一行小字）。
2. 設定：
   - **「過期時間」**（**Expire After**）：選 **7 天**（或更短，例如 1 天）。
   - **「最多使用次數」**（**Max number of uses**）：選你同組同學的人數，例如 `5`。
   - **「授予暫時成員資格」**（Grant temporary membership）：**保持關閉**。
3. 點 **「產生新連結」**（**Generate a New Link**）。

### 4-3 把連結傳給同學

1. 點連結旁邊的 **「複製」**（**Copy**）。
2. 用你平常聯絡同學的方式（Line、Email 等）傳給他們。
3. 同學點連結，按 **「接受邀請」**（**Accept Invite**）就會進到你的 Server。

### 4-4 確認同學進得來

同學加入後，Server 右邊的成員列表會看到他們。要看列表，點右上角的 **人像圖示**（顯示成員名單）。

### 4-5 萬一連結外流了

1. 回到 Server 名稱選單 → **「伺服器設定」**（**Server Settings**） → 左邊選單 **「邀請」**（**Invites**）。
2. 看到所有還有效的連結，在不要的那一條右邊按 **叉叉**，連結立刻失效。
